Olist E-commerce Data Analysis

Project Overview

This project focuses on analyzing Olist E-commerce data to understand sales performance, customer purchasing patterns, product category performance, payment methods, and order delivery performance.

The objective is to extract meaningful business insights and support data-driven decision-making.

Tools & Technologies

Python (Pandas, NumPy)

MySQL

Power BI

DAX

Excel

Project Workflow

Data Loading and Inspection using Python

Data Cleaning and Quality Checks

Data Analysis using SQL

Data Transformation and Visualization using Power BI

Business Insights and Recommendations

Key Performance Indicators

Total Revenue: Approximately ₹16 Million

Total Orders: Approximately 99,000

Average Order Value: ₹162.25

Key Business Insights

Beleza Saúde was the highest revenue-generating product category.

Relogios Presentes ranked second in revenue generation.

May recorded the highest monthly revenue.

Credit Card was the most-used payment method.

Approximately 96,000 orders were delivered.

Business Recommendations

Focus on high-performing product categories.

Plan marketing campaigns around strong sales periods.

Maintain convenient and secure payment options.

Monitor delivery performance and reduce cancellations.

Use customer and sales trends to improve business decisions.
